# 小米 · 光影之间

Xiaomi 15 Ultra 产品概念页，包含七个板块。初版由 GPT-6 Astra / medium 使用技能生成，展示版本经过多轮用户反馈与协作修订。

## 页面内容

| 板块 | 内容与交互 |
|---|---|
| 主视觉 | 官方产品摄影、流动材质背景、标题入场 |
| 机身设计 | 三种配色切换，图片与名称同步，指针倾斜反馈 |
| 镜头探索 | 23 / 70 / 100mm 样张切换、图片放大与关闭 |
| 光学细节 | 相机模组特写、滚动文字揭示 |
| 旗舰体验 | 屏幕、官方芯片图片与系统介绍 |
| 摄影套装 | 套装图片与详情弹窗 |
| 探索清单 | 加入 / 取消本次页面清单，返回顶部 |

## 使用资源

- React Bits：Silk、BlurText、ScrollReveal、TiltedCard。
- Animate UI：完整 Button、ButtonPrimitive、Slot。
- Radix Themes：弹窗；Swiper EffectFade：配色与镜头画廊。
- Phosphor：图标；Noto Sans SC：本地字体。
- [小米官方产品页](https://www.mi.com/global/product/xiaomi-15-ultra/)：产品摄影、Logo、芯片图与样张。

## 版本与检查

修订增加了公开按钮和文字组件，替换品牌标识及芯片示意，并统一背景、文字和控件的动效策略。本地展示按任务要求播放完整动效；发布构建默认响应系统减少动效偏好。

已检查宽屏、窄屏、配色与镜头切换、弹窗关闭和探索清单操作。此次截图与录像直接采集用户认可的修订版本，采集期间未修改页面。真实手机、Safari 和低性能设备未测试。
