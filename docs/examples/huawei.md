# 华为产品概念页：独立任务记录

## 测试条件

- 日期：2026-09-28。
- 模型：GPT-6 Astra，medium。
- 新 agent，不继承设计会话；只收到一次任务与固定的 skill 快照。
- 主题：华为产品官网概念，至少 6 个主要板块，向下浏览，设计自行发挥。
- 要求：实际使用公共组件与素材，本地预览默认完整动效，没有全局动效开关。
- 执行过程中没有追加设计指导；最终输出没有由评审者修改。

公开版技能对称谓和打包作了整理；没有把本案例的配色、产品或版式写成后续任务的固定模板。案例验证的是整理前的同一设计方法，不是重新跑过所有模型。

## 输入的核心任务

```text
使用 community-ui-craft，设计制作一个华为产品官网的本地 HTML 概念版。
至少 6 个主要内容板块，向下滚动浏览；重点是 UI 设计。
产品选择、内容、风格、布局、交互与技术方案自行发挥。
实际复用公共组件和素材，本地预览默认呈现完整动效，
不设置全局动效开关。完成后给出可查看的预览和文件。
```

原任务还规定使用独立空目录、不读取旧成品、不修改其他项目、不公开部署，以及自行验证。个人设备路径和会话标识不属于可复用任务内容，因此没有放入本仓库。

## 实际成品

| 板块 | 内容 | 主要可见机制 |
|---|---|---|
| 1. 主视觉 | Pura 80 Ultra | 连续金色光场、指针反馈、逐字标题、产品入场 |
| 2. 精选产品 | 手机、手表、平板 | 官方产品图、对应详情、完整公开按钮 |
| 3. Pura 影像 | 风光与镜头探索 | Swiper 转场，图像与说明同步 |
| 4. 光影美学 | 金色与黑色 | 两套真实产品素材与状态切换 |
| 5. 运动与生活 | WATCH GT 6 | 户外摄影、产品入场、详情入口 |
| 6. 灵感随行 | MatePad Pro 12 | 浅色章节、大幅产品画面与对应详情 |
| 7. 服务支持 | 支持与探索出口 | 官方服务链接、章节文字与光场延续 |

核心公共组件为 React Bits ColorBends / BlurText、Animate UI Button、Radix Themes、Swiper 与 Phosphor。布局和业务状态由 agent 整合，部分产品动作使用自编 Motion 编排，不宣称全部视觉都是直接复制的组件。

## 自主修正与独立复核

agent 自行发现并修正了背景几乎不可见、标题样式覆盖、标注遮挡与资源下载问题。

交付后另行只读复核：1440×1000、390×844 和 352×668；使用新浏览器上下文并阻断外部资源请求。在系统上报减少动效的条件下，本地明确要求完整播放的预览仍有可见背景和文字动效。图片加载、配色/影像切换、详情关闭、手机导航均可用；未发现页面运行异常或横向溢出。

“一次任务”包含 agent 内部的资源检索、编写、运行、查看和修正，不表示只输出一遍代码便结束。

## 仍然存在的不足

- 352px 窄栏有句号单独换行，部分辅助文字偏小。
- 某些导航仍为原生按钮配定制样式，未完全覆盖完整社区控件。
- 弹窗可关闭，但键盘焦点未恢复到打开它的按钮。
- 部分官方图在大尺寸下偏软，部分图片被重复使用。
- 局部 CSS 过渡没有完全共用本地完整动效策略；背景、文字及主按钮的动作已单独验证。

这些问题保留在录屏与截图对应的原始成品中，没有为展示而返工，也没有抹去测试限制。用户对这次独立生成结果表示满意，但单次案例不等于统计意义上的稳定成功率。尚未完成跨模型对照，也未实测真实手机硬件、Safari 或低端设备帧率。
