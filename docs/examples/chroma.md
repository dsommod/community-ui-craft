# CHROMA · 键盘交互画廊

创建模型：GPT-6 Sol / medium（创建者提供）。本记录展示完成后的界面与真实操作片段。

![CHROMA · 键盘交互画廊 总览](../media/chroma-overview.jpg)

## 界面与交互

色域画廊、方向键切换、形态与配色、沉浸模式。

## 使用的资源

React Bits ColorBends / BlurText、Animate UI、Lucide、Three.js、Motion。组件参数、页面布局和状态逻辑根据主题适配。

## 录制

原始浏览器视口为 1600 × 900。录制使用独立浏览器环境，启用页面动效；内容来自原页面，未重绘成视频道具。宣传片加入标题、章节切换和节奏调整，登山与汇报片段有适度加速。
