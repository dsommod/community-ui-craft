# 数据交互：优先完整组件，保持数据语义

## 选什么

| 需求 | 首选方向 | 何时换一种 |
|---|---|---|
| 普通业务图表、tooltip、图例、缩放、状态更新 | ECharts 官方示例 | 已有成熟图表库够用则保持；只需静态小图时无需重型新依赖 |
| 特殊关系图、科学波形、范围刷选与联动 | D3 官方示例与模块 | 数据结构标准、希望少写行为时用 ECharts |
| React 中已有 Recharts 体系 | 沿用现有组件；按实际缺口补齐 | 不为“更高级”无理由重写全部图表 |
| 教学、生成艺术、粒子、可玩信号画布 | p5 | 精确图轴/图例和可访问数据表优先用图表库 |
| 三维产品/空间数据 | Three.js，必要时配对应地图/3D库 | 没有空间含义的数据不要包装成倾斜立体柱图 |

Three.js、p5、D3 不是必须全装的套餐。ECharts 是成熟图表能力，D3 是更灵活的数据与视觉工具；“能画出来”不是它们之间唯一的选择依据。

## 从官方示例开始

- ECharts [示例](https://echarts.apache.org/examples/en/index.html)、[源码](https://github.com/apache/echarts-examples)、[入门](https://echarts.apache.org/handbook/en/get-started/)、[数据过渡](https://echarts.apache.org/handbook/en/how-to/animation/transition/)。先选与数据结构对应的 chart type，再取 option；不要选择最炫图形后强行凑数据。
- D3 [brush](https://d3js.org/d3-brush)、[zoom](https://d3js.org/d3-zoom)、[Focus + Context 示例](https://observablehq.com/@d3/focus-context)。核对示例代码许可；不要混淆库 ISC 与某个历史 gist 的其他许可。

建立数据适配层，使图表直接消费筛选后的真实记录，统计数字、图例、表格和图形来自同一个状态。演示数据可固定种子，标明演示；不能伪造接口成功、企业业绩或科研结果。

## 值得实现的交互

1. 悬停/点击显示单位、日期/对象和精确值，提示不跑出容器。
2. 图例选择更新系列，选中对象联动明细；提供清除/复位。
3. 长序列才需要范围刷选或 dataZoom；只比较四个方法时无需装饰性缩放条。
4. 曲线共用时间/深度轴时用共享游标；纵轴量纲仍分别标注。
5. 键盘或触屏能完成关键选择；悬停不是唯一读取数据的方法。
6. 无数据、请求失败、加载中、数据缺失都是明确状态；不要留空白画布或假数字。

## 保持实例与视觉连续性

ECharts 在有效尺寸的容器初始化一次，更新用 `setOption`，使用稳定的 series/data 身份。在隐藏 Tab/Slide 变为可见后 resize。监听容器尺寸而非仅监听窗口；离开真正销毁实例的视图时 dispose。采用按需导入时，确认 Tooltip、Legend、DataZoom、AxisPointer、Aria 等实际用到的模块已经注册。

D3 使用稳定 key 的数据 join 和 update/exit，而非每次清空 SVG。范围变化时同步轴、路径、提示和摘要，处理 zoom↔brush 相互调用，避免递归更新。统一事件生命周期，移除旧监听。

React 项目要确认 StrictMode 下不会留下双 canvas/双监听。SVG renderer 适合许多轻量图和清晰导出，大数据时根据实测选择 Canvas；不要把一种 renderer 规定为全部项目的答案。

动效是状态变化的可视反馈，不是伪造数据随时间变化。普通同量纲变化可以过渡；切换 SNR、MSE 等不同指标时明确单位和尺度更新，必要时短暂淡入而非把两种量纲形变成同一过程。

## 科研、金额与监控读数

- 精确值标签直接显示最终真实值；不要 CountUp 出一串未发生的中间结果。装饰营销数字是否滚动取决于语义。
- 保留原表、公式、量纲和升降方向。不同单位不能无定义地合成一个总分或雷达面积。
- 只有离散实验点时不插值成平滑连续实验；折线是否连接有明确说明。
- 不随意截断柱图基线制造差距；需要放大差异时用合理点图/明确刻度与精确值。
- 没有原始数据只有论文截图时，做放大、区域指引和出处，不发明数值 tooltip。
- 真实结果、模拟数据、教学示意分别标识；不把一致性检查升级成独立验证，不新增未做的显著性结论。
- 源图保持原色标；不同色标的热图不能直接凭颜色强弱比较。

## 成功的图表区域应同时回答

这是什么指标？范围/单位是什么？哪些元素可以操作？当前选择对应哪批记录？精确值在哪里？差异支持什么结论？没有数据时会怎样？如果只回答“能动”，还没有形成可用的数据界面。
